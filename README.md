# TikTok Linker

Aplicación para conectar TikTok Live con TikFinity mediante WebSocket.

## Descargar

Descarga la última versión para Windows:

[Download TikTok Linker V3.0.0](https://github.com/Nirvanatistos/TikTokLinker-Releases/releases/latest/download/TikTok-Linker-3.0.0-Setup.exe)

Consulta las notas de versión y versiones anteriores en la [página de Releases](https://github.com/Nirvanatistos/TikTokLinker-Releases/releases).

## Características

- Conexión con TikFinity mediante WebSocket.
- Gestión personalizada de comandos.
- Texto a voz.
- Detección del regalo Quiéreme.
- Generación de `quiereme.txt` para SAMMI.
- Instalador para Windows.

## Requisitos

- Windows.
- TikFinity configurado.
- Conexión WebSocket disponible.
